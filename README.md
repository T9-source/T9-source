### What I do

I'm an engineer who ships systems people actually run their work on —
management systems, e-commerce platforms and Android delivery apps end-to-end,
from database schema to production deploy. On the security side, I build
open-source reconnaissance tooling used by pentesters and bug-bounty hunters.

- 🏗️ **Custom management systems** — Laravel + MySQL, role-based, built around real business workflows
- 🛒 **E-commerce & delivery platforms** — Next.js + Prisma, Android clients, admin dashboards
- 🔓 **Security tooling** — multi-source origin-discovery, built to be fast, scriptable and honest
- ⬡ **Cinematic web** — WebGL landing experiences with zero build overhead

### Open source

#### 🔓 [CloudFail-Killer (`cloudkill`)](https://github.com/T9-source/cloudfail-killer)

Multi-source, IPv6-native reconnaissance that finds origin servers hidden
behind Cloudflare — **13+ passive & active data sources**, a staged enrichment
pipeline, confidence-scored results, signed reports. Built for pentesters and
bug-bounty hunters who need the origin, not the noise.

```bash
pip install cloudkill
```
