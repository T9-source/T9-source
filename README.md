### About

I design and build complete systems — management platforms, e-commerce stores
and delivery applications — from database schema through backend and frontend
to production deploy. Several of these systems run real businesses today.

On the security side, I develop open-source reconnaissance tooling used in
penetration-testing and bug-bounty workflows, published on PyPI.

- **Management systems** — Laravel + MySQL, role-based, built around real business workflows
- **E-commerce & delivery** — Next.js + Prisma, Android clients, admin dashboards
- **Security tooling** — multi-source origin-discovery, scriptable, CI-friendly
- **Web engineering** — WebGL landing experiences with zero build overhead

### Open source

#### [CloudFail-Killer (`cloudkill`)](https://github.com/T9-source/cloudfail-killer) — v0.8.0

Multi-source, IPv6-native reconnaissance that identifies origin servers hidden
behind Cloudflare. 13+ passive and active data sources, a staged enrichment
pipeline, confidence-scored results and signed reports.
